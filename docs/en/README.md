## Translation rules

1. Keep the chapter structure: **conclusion → why (mechanism) → how (commands) → verify → common misreads**.
2. Keep commands and paths identical to the Chinese page. Only prose is translated.
3. Do not translate tool names, config keys, error strings, or file names.
4. Update the status table above in the same pull request.

Until a chapter is translated, the Chinese page is the source of truth; the
copy-pasteable JSON/YAML blocks there are language-neutral.
